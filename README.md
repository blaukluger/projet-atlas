# Projet Altas

## Application pour demander et donner de l'aide informatique

- Gérer les profils et chaque roles
- Signaler un probleme et le resoudre
- Voir et gérer l'ensemble des tickets et des comptes

## Organisation du Projet
- backend : la partie cacher et serveur qui traite les données de mon Application (avec Fast API)
- Frontend : la partie visible de mon Application
